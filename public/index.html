What it does

A focused reader for bookmarks you already sync. Nothing more, on purpose.

  • Decrypted on your device

    PBKDF2 and AES-GCM run in your browser via the Web Crypto API, matching the official client exactly. The service only ever hands over an encrypted blob.

  • Installs to your homescreen

    Add to Home Screen on iOS Safari or Android Chrome and it launches standalone, with no browser chrome — the closest thing to a native app.

  • Search everything

    Filter across titles, URLs, descriptions and tags at once. Results show the folder each bookmark came from, so a flat list still makes sense.

  • Folders, and open-all

    Browse your real hierarchy with collapsible folders — or open every bookmark in a folder at once, each in its own tab.

  • Works offline

    The last synced copy is cached — still encrypted — so it opens without a connection. Stale data is always labelled as such, never passed off as fresh.

  • Nothing phones home

    No analytics, no telemetry, no third-party requests of any kind. The only host it contacts is the xBrowserSync service you configure.

Your password never leaves the browser

xBrowserSync is anonymous and end-to-end encrypted by design. This client preserves that: the server sees an opaque blob and a sync ID, and nothing else.

  1. Derive Your password and sync ID go through PBKDF2-SHA256, 250,000 rounds, in-page.
  2. Fetch The app requests the encrypted blob. Only the sync ID crosses the network.
  3. Decrypt AES-GCM, then LZ-UTF8 decompression, then render. All locally, every time.

Stored on your device

  • Service URL
  • Sync ID
  • Bookmarks, still encrypted
  • Decryption key, only if you stay signed in

Never stored, never sent

  • Your password
  • Decrypted bookmarks

Local storage is not encrypted at rest. On a shared device, untick “stay signed in” so a password is required each launch.

Add it to your homescreen

You will need your sync ID and password from the xBrowserSync browser extension.

iOS & iPadOS

  1. Open this site in Safari — not Chrome or an in-app browser.
  2. Tap Open the app above.
  3. Tap Share, then Add to Home Screen.
  4. Launch it from the new icon to get a standalone window.

Android

  1. Open this site in Chrome.
  2. Tap Open the app above.
  3. Tap the ⋮ menu, then Install app. Chrome may offer this on its own.
  4. Launch it from the new icon.

Run your own copy

It is a static site with no backend. Point Netlify at the repository and it deploys as is — HTTPS included, which the Web Crypto API and PWA install both require.

Works with the official service or any self-hosted xBrowserSync instance that allows cross-origin requests. Nothing about this client is tied to a particular host.
